二、Windows 学术数据检测工具设计与实现
工具概述
这是一个基于 Python 开发的轻量级 Windows 桌面应用，能够自动分析 Excel 文件中的数据，检测上述统计学异常并生成详细的可疑点报告。工具无需安装 Python 环境，可直接打包为 exe 文件运行。
技术栈
核心语言：Python 3.10+
GUI 框架：tkinter（Python 标准库，无需额外安装）
数据处理：pandas, numpy
统计分析：scipy
报告生成：HTML + 内嵌图表
打包工具：PyInstaller
