# 实验数据自检工具

基于统计学方法自动检测 Excel/CSV 数据中的异常模式，辅助研究人员自查实验数据。

## 检测项目

| 检查项目 | 检查方法 | 可疑迹象 | 严重程度 |
|---|---|---|---|
| 末位数字分布 | 提取所有数值型数据的末位数字，统计 0-9 出现频率 | 某几个数字出现频率显著高于其他（如 0 和 5 占比 > 60%） | ⭐⭐⭐⭐⭐ |
| 完美等差数列 | 检查相邻数据点是否存在固定差值 | 连续 3 个以上数据点差值完全相同（误差 < 1e-6） | ⭐⭐⭐⭐⭐ |
| 数据完全重复 | 检查所有数值是否存在完全相同的情况 | 小数点后两位及以上完全相同的数据点超过 5% | ⭐⭐⭐⭐⭐ |
| 数据精度一致性 | 检查所有数据的小数位数 | 大部分数据保留 1 位小数，少数突然变成 2 位且末位集中 | ⭐⭐⭐⭐ |
| 标准差异常 | 计算各组数据的标准差 | 标准差过小（<均值的 1%）或过大（> 均值的 100%） | ⭐⭐⭐⭐ |
| 线性相关性过强 | 计算不同实验组之间的相关系数 | 相关系数 > 0.99 且无生物学解释 | ⭐⭐⭐⭐ |

## 技术栈

| 类别 | 技术 |
|---|---|
| 核心语言 | Python 3.10+ |
| GUI 框架 | tkinter（Python 标准库） |
| 数据处理 | pandas, numpy |
| 统计分析 | scipy |
| 报告生成 | HTML + matplotlib 内嵌图表 |
| 打包工具 | PyInstaller |

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 运行
python main.py
```

## 打包为 exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "实验数据自检工具" main.py
```
